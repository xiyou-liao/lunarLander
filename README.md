# Lunar Lander

This is based on a Lunar Lander game. Help Kirby land on the moon and mine diamonds!

## Goal
Land on the diamond ore blocks to accomplish the mission.
If you touch any other block, you will crash and fail the mission.

## Game Controls
- To add horizontal acceleration left or right: Press A and/or D, respectively
- To accelerate upwards: Press W
- To reset the game: Press R
- To quit the game: Press Q

# Lunar Lander

A Kirby-themed Lunar Lander game where you help Kirby land on the moon and mine diamonds!

## Goal
Land on the **diamond ore blocks** to successfully complete the mission.
**Be careful!** If you touch any other block, Kirby will crash and the mission will fail.

## Game Controls
| Key | Action |
|-----|--------|
| **A** | Accelerate left |
| **D** | Accelerate right |
| **W** | Accelerate upward |
| **R** | Reset the game |
| **Q** | Quit the game |

## Game Physics

Just like on the moon, there is **no air resistance**. 
If you send Kirby off in one direction, he will continue in that direction 
forever unless an acceleration is applied to change his velocity.
- There is still a little bit of lunar gravity so Kirby will fall if no upward thrust is applied.
